# Quinta Los Álamos · web

Dos cabañas en un parque cerrado de San Pedro, Buenos Aires.

Se ve en **https://seerystudio.github.io/los-alamos-web/**

- `index.html` — la página principal
- `cabana-grande.html` y `cabana-chica.html` — el recorrido de cada cabaña

Copia publicable de `los-alamos-landing/` del vault de trabajo. Mientras no esté el dominio propio,
las páginas llevan `noindex` para no competir con él en Google.
